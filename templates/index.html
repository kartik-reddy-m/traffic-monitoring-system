About the Smart Traffic Monitoring & Violation Detection System

1. Objective & Overview

This web application is a complete, automated intelligent transportation system (ITS) designed to monitor vehicle flow, estimate real-time traffic density, and detect common road safety violations using deep learning and computer vision.

2. Architecture & Tech Stack

  • AI / Deep Learning: Ultralytics YOLOv8 (nano architecture) for multi-class vehicle detection (Cars, Motorcycles, Buses, Trucks, Bicycles) and pedestrians/riders.
  • Multi-Object Tracking: Hungarian Algorithm assignment via scipy.optimize.linear_sum_assignment combining spatial IoU and centroid distance metrics to maintain unique vehicle IDs, prevent duplicate counting, and compute velocity vectors.
  • Computer Vision: OpenCV for frame-by-frame processing, stop-line intersection geometry, trajectory tracking, and head ROI computer vision inspection.
  • Backend Framework: FastAPI with asynchronous endpoints, streaming MJPEG responses, and dependency injection.
  • Database: SQLite with SQLAlchemy ORM storing detailed violation records and periodic traffic density logs.
  • Frontend: Clean, responsive vanilla HTML5, CSS3, and JavaScript dashboard without unnecessary decorative bloat.

3. Violation Detection Methodologies

🔴 Red-Light Signal Violation

A configurable virtual stop line is monitored in synchrony with a virtual traffic signal state machine. When the signal is RED, any tracked vehicle whose motion vector crosses the stop line triggers a Red Light violation and captures full frame evidence with the active signal indicator.

🔄 Wrong-Way Driving Detection

Vehicles maintain a trajectory vector over historical frames. The normalized displacement vector is computed against the configured lane flow direction. If the dot product indicates opposite movement (> 115° divergence) over sustained frames, a Wrong-Way violation is logged.

🚴 Triple Riding Detection

For each tracked two-wheeler (motorcycle or bicycle), the system computes spatial containment of detected persons within the upper and central bounding envelope of the bike. When 3 or more distinct person bounding boxes are associated with a single bike, a Triple Riding infraction is flagged.

⛑ No Helmet Detection

For riders detected on two-wheelers, the upper crown/head region is isolated. The computer vision pipeline analyzes skin/hair color tone distributions vs smooth circular helmet protective contours. A custom YOLO helmet model (helmet_yolov8.pt) can also be placed into the models/ directory to automatically upgrade to deep-learned helmet inference.
